# EventEase-Blazor-Event-Management-Application

EventEase is an event management web application developed using
Blazor WebAssembly and C#.

The project was created as part of a front-end development activity
using Microsoft Copilot.

## Features

- Browse available events
- Reusable Event Card component
- View individual event details
- Blazor routing
- Registration form
- Form validation
- Two-way data binding
- User session state management
- Attendance tracking
- Invalid event handling
- Responsive interface

## Technologies Used

- Blazor WebAssembly
- C#
- Razor Components
- HTML
- CSS
- .NET
- Microsoft Copilot

## Project Structure

The application contains reusable components, models, services,
pages, and CSS styling.

Key files include:

- `Components/EventCard.razor` - reusable event card
- `Pages/Events.razor` - displays available events
- `Pages/EventDetails.razor` - event information and routing
- `Pages/Register.razor` - registration and validation
- `Pages/Attendance.razor` - attendance tracking
- `Services/UserSessionService.cs` - application state management

## Running the Project

Make sure the .NET SDK is installed.
